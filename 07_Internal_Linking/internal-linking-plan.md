## Business Page Links
Only add links to these pages when real URLs exist:
- Official menu
- Contact page
- Directions/location page
- Booking/reservation page, if offered
- Accessibility or FAQ information, if available

## Anchor Text Guidance
- Use descriptive, natural phrases that fit the sentence.
- Avoid repeating the exact same keyword anchor in every paragraph.
- Link where the destination answers a likely follow-up question.
- Test every link after publishing.
- Keep the number of links useful rather than excessive.

## QA Checklist
- [ ] All destination pages exist.
- [ ] URLs are correct and secure where applicable.
- [ ] Links work on desktop and mobile.
- [ ] Anchor text describes the destination.
- [ ] No placeholder URL remains.
- [ ] Links are useful in context.
