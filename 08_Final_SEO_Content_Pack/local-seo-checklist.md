# Local SEO Checklist

## Business Information
- [ ] Confirm exact business name and spelling.
- [ ] Confirm full address and map pin.
- [ ] Confirm phone number and official website.
- [ ] Confirm opening hours and holiday exceptions.
- [ ] Confirm current menu/services and prices.
- [ ] Confirm facilities and accessibility information.
- [ ] Ensure website and business profile details are consistent.

## On-page Content
- [ ] Use a clear, unique title and meta description for each page.
- [ ] Include location terms only where natural and accurate.
- [ ] Answer the reader's main question near the beginning.
- [ ] Use a logical H1–H3 hierarchy.
- [ ] Add real internal links to relevant pages.
- [ ] Include a clear next step with a verified URL.
- [ ] Avoid keyword stuffing and unsupported “best” claims.

## Local Trust and Accuracy
- [ ] Verify each location-specific statement.
- [ ] Do not invent reviews, ratings, awards, or customer quotes.
- [ ] Do not claim facilities without confirmation.
- [ ] Keep contact and location details current.
- [ ] Check that all page links work.
- [ ] Add structured data only if implemented correctly and supported by visible page content.

## Measurement
- [ ] Set up appropriate analytics and search performance measurement if available.
- [ ] Record publication/update dates.
- [ ] Review search queries and page performance after publication.
- [ ] Update content based on real evidence, not assumptions.
